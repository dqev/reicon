# Reicon Figma Plugin Guide

Integrate Reicon directly into your Figma design workspace using the official Figma plugin. Search 2,700+ vectors, customize stroke weights, toggle outline/filled variants, and drag-and-drop SVG shapes directly onto your active canvases.

---

### What You Can Accomplish
- Access all 2,700+ icons directly inside Figma
- Toggle between Outline and Filled weight variants instantly
- Set custom hex colors or inherit local Figma paint styles
- Insert clean, vector-grouped SVG paths into any frame
- Search icons by keyword, category, or alias
- Maintain consistent stroke weights across your design system

---

### 1. Installation

Visit the official plugin page on the Figma Community to install the extension to your workspace:

[Open Figma Community Plugin](https://www.figma.com/community/plugin/1652983191908763066)

Alternatively, search for **Reicon** in the Figma Community tab under **Plugins** and click **Save** or **Run**.

---

### 2. Workflow & Guide

How to open and insert vector components inside a design file:

1. **Open the plugin panel**: Right-click inside any Figma canvas, select **Plugins** &rarr; **Reicon**, or search for "Reicon" in the resource panel (`Cmd + P` or `Ctrl + P` / `Shift + I`).
2. **Search or Filter**: Browse through categories (Arrows, Communication, System, Media, etc.) or type keywords in the search bar.
3. **Select Weight and Color**: Choose between **Outline** and **Filled** styles using the toggle swatches, and pick a custom hex color.
4. **Insert Vector Shape**: Click any icon card to instantly spawn the vector group at the center of your active viewport or selection frame.

---

### 3. Component Variants & Weights

Reicon icons in Figma are designed as clean vector groups:

- **Outline Icons**: Built with standard 1.5px stroke paths that scale cleanly with vector resizing.
- **Filled Icons**: Solid silhouette vectors for high visual emphasis.
- **Vector Cleanliness**: No extra hidden layers, clipped masks, or unnecessary group nesting.

---

### 4. Design Tokens & Styles

- **Color Swatches**: Apply your Figma design system color tokens directly to inserted icons.
- **Auto Layout Ready**: Icons spawn inside square frames (24x24 by default), making them drop-in ready for Auto Layout buttons, inputs, and navigation bars.
- **Batch Exporting**: Select multiple Reicon frames and export them as SVGs, PNGs, or PDF assets for developer handoff.

---

### 5. Keyboard Shortcuts & Tips

- `Cmd + Option + P` / `Ctrl + Alt + P`: Re-run the last used plugin (Reicon) instantly.
- `Shift + I`: Open the Figma Resource modal to search plugins.
- **Tip**: Keep the Reicon plugin window open while designing to quickly drag multiple icons onto your artboard.
